# ⏱️ Chronos Pomodoro

Aplicação web de gestão de tempo e produtividade baseada na técnica Pomodoro, permitindo alternar entre ciclos de foco e descanso enquanto organiza tarefas da sessão.

🔗 **Acesse o projeto online:** [chronos-plum-ten.vercel.app](https://chronos-plum-ten.vercel.app)

## 🚀 Funcionalidades
- Temporizador configurável para ciclos de foco, descanso curto e descanso longo
- Associação de tarefas ao ciclo ativo
- Histórico de ciclos concluídos e interrompidos
- Alertas visuais e sonoros ao finalizar cada etapa

## 🛠️ Tecnologias Utilizadas
- **React** + **Vite**
- **TypeScript**
- **CSS Modules / Tailwind CSS**
- **Context API / Hooks customizados**

## 💻 Como rodar localmente

```bash
# Clone o repositório
git clone [https://github.com/Railapa/Chronos.git](https://github.com/Railapa/Chronos.git)

# Acesse a pasta do projeto
cd Chronos/chronos-pomodoro

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
